# 🎨 Инструкция по настройке UI Toolkit для DnD Dynamics

## ✅ Шаг 1: Генерация UI ассетов

1. Откройте Unity Editor
2. Перейдите в меню: **Tools → DnD Dynamics → Generate UI Assets**
3. Дождитесь сообщения в консоли: `✅ UI Assets generated successfully`

Это создаст следующие файлы:
```
Assets/DnD-Dynamics/Resources/UI/
├── Styles/
│   └── Common.uss          # Общие стили (цвета, шрифты, размеры)
└── Layouts/
    ├── MainMenu.uxml       # Главное меню
    ├── CharacterCreator.uxml  # Создание персонажа
    ├── Handbook.uxml       # Справочник
    ├── DMTools.uxml        # Инструменты мастера
    └── CombatTracker.uxml  # Трекер боя
```

## ✅ Шаг 2: Настройка сцены

### Вариант A: Автоматическая настройка (рекомендуется)

1. Создайте новую сцену: **File → New Scene → 2D**
2. Сохраните сцену как `MainScene` в папке `Assets/DnD-Dynamics/Scenes/`
3. Создайте пустой GameObject и назовите его `UI_Manager`
4. Добавьте компонент `UIManager` (скрипт уже создан)
5. Перетащите все `.uxml` файлы из `Resources/UI/Layouts/` в соответствующие поля скрипта:
   - **Main Menu Layout** → `MainMenu.uxml`
   - **Character Creator Layout** → `CharacterCreator.uxml`
   - **Handbook Layout** → `Handbook.uxml`
   - **DM Tools Layout** → `DMTools.uxml`
   - **Combat Tracker Layout** → `CombatTracker.uxml`
6. Перетащите `Common.uss` в поле **Common Styles**

### Вариант B: Использование префаба

Создайте префаб для повторного использования:
1. Настройте объект как в варианте A
2. Перетащите `UI_Manager` из иерархии в папку `Assets/DnD-Dynamics/Prefabs/`
3. Теперь можно перетаскивать префаб на любую сцену

## ✅ Шаг 3: Запуск

1. Нажмите **Play** в Unity Editor
2. Вы увидите главное меню с кнопками:
   - 🎮 Новая игра / Персонажи
   - 📖 Справочник
   - ⚔️ Трекер Боя
   - 🎲 Инструменты Мастера
   - ⚙️ Настройки
   - 🚪 Выход

## 🎯 Функционал окон

### Главное меню
- Навигация ко всем основным разделам приложения
- Кнопка выхода из приложения

### Создание персонажа
- Ввод имени, выбор расы и класса
- 6 характеристик (STR, DEX, CON, INT, WIS, CHA)
- Кнопка "Бросить характеристики" (генерирует 3d6, берет лучший)
- Вкладки: Снаряжение, Заклинания, Биография
- Сохранение/отмена

### Справочник (Handbook)
- Поиск по названию
- Фильтрация по категориям (Расы, Классы, Заклинания, Предметы, Монстры)
- Переключатель "Только Homebrew"
- Список элементов слева, детальная информация справа
- Кнопки редактирования/удаления

### Инструменты Мастера (DM Tools)
- **Заметки**: список заметок слева, редактор справа
- **Быстрый бросок кубов**: d4, d6, d8, d10, d12, d20, d100
- Отображение последнего броска
- Генератор случайных имен NPC

### Трекер Боя (Combat Tracker)
- Кнопки управления боем (Начать, Следующий ход, Завершить)
- Отображение текущего хода
- Добавление монстров из бестиария
- Добавление персонажей игроков
- Детали выбранного участника (HP, AC, Инициатива)
- Управление состояниями и эффектами
- Лог боя
- Кнопки нанесения урона и лечения

## 🎨 Стилизация

Все стили определены в `Common.uss`:
- **Цветовая схема**: Темная тема с золотым акцентом (#d4a017)
- **Шрифты**: Roboto (требуется установить в проект)
- **Размеры**: Адаптивная верстка с flexbox

### Изменение темы
Откройте `Common.uss` и измените переменные в `:root`:
```css
:root {
    --bg-color: #1e1e1e;      /* Фон */
    --panel-color: #2d2d2d;   /* Панели */
    --accent-color: #d4a017;  /* Акцент (золотой) */
    --danger-color: #cf4545;  /* Опасность (красный) */
    --success-color: #45cf68; /* Успех (зеленый) */
}
```

## 🔧 Интеграция с существующей архитектурой

Для подключения к MVP архитектуре:

1. В `UIManager.cs` замените заглушки методов на вызовы Presenter'ов:
```csharp
private void OnSaveCharacter()
{
    var presenter = Resolve<CharacterPresenter>(); // Через Zenject
    presenter.SaveCharacter();
}
```

2. Используйте Zenject для внедрения зависимостей в `UIManager`

3. Для динамического наполнения списков используйте `ListView.MakeItem` и `ListView.BindItem`

## 🐛 Решение проблем

### Ошибка: "Layout not assigned"
- Проверьте, что все `.uxml` файлы перетащены в инспекторе на компонент `UIManager`

### Ошибка: "StyleSheet not found"
- Убедитесь, что `Common.uss` существует в `Resources/UI/Styles/`

### UI не отображается
- Проверьте, что на сцене есть `UIDocument` компонент
- Убедитесь, что камера настроена для UI (если используется Canvas)

### Стили не применяются
- Проверьте путь к стилю в UXML файлах
- Убедитесь, что классы совпадают (`class="window-root"` и т.д.)

## 📝 Примечания

- UI Toolkit работает независимо от системы Canvas
- Поддерживает runtime модификацию через C# API
- Рекомендуется использовать `Q<T>()` для поиска элементов по имени
- Все события обрабатываются через `clicked`, `RegisterValueChangedCallback` и др.
